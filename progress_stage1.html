Research Progress · Milestone 1

Can we see an emergent event coming before it happens?

We study prediction as an information problem, using the spontaneous birth of self-replicating programs as a clean, fully observable test case. Forecasting is the measuring instrument; information is the object of study.

Stage 1 complete

The substrate and its transition detector are reproduced from scratch and verified. Self-replicators now emerge on demand from random bytes — the event the whole project is built to forecast.

The result

Life emerges from random code — and we can measure the moment it does

A “primordial soup” of 4,096 programs, each 64 random bytes, is left to interact under a 10-instruction language (an extended Brainfuck). No fitness function. No goal. No seeded replicator. Within a few dozen epochs, self-replicating structure takes over the soup. The high-order-entropy detector — how much of the soup is explained by relations between bytes rather than the bytes themselves — captures the transition exactly.

What was built

An instrument, not just a simulation

Four components, each written from scratch so we understand — and can instrument — every byte. This is what the forecasting and information-measurement work in later stages plugs into.

BFF interpreter bff.py

The 10-instruction self-modifying language. Code and data share one tape, so programs rewrite themselves and each other.

Primordial soup run_soup.py

Thousands of programs paired at random each epoch and executed — the Turing-gas dynamics that let replicators arise.

Transition detector detector.py

High-order entropy = Shannon entropy − compressed (Kolmogorov) size. Near 0 for noise; it climbs sharply when life appears.

Correctness suite test_bff.py

Targeted semantic tests plus fuzz-equivalence against a transparent reference over 3,000 random tapes.

Why you can trust the engine

Verified against a readable reference

A fast simulator is only useful if it is correct. Every instruction is checked against a slow, obviously-faithful reimplementation of the paper’s instruction set — on thousands of random programs, both must end in byte-identical states.

An honest framing

This milestone reproduces published work (Agüera y Arcas et al., 2024) — that is the point of Stage 1: a trustworthy foundation and a working ground-truth label. The project’s own contribution begins at Stage 3, and its novelty is a careful integration — forecasting an emergence event and measuring the information behind it — not a new theorem.

By design, even a fully negative outcome is a result: absence of predictive information is reported as a measured bound in bits, not a failure.
